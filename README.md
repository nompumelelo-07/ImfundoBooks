 ImfundoBooks - University Textbook Exchange Platform

> Bridging the gap between students who need textbooks and those selling them | *"Imfundo" means "Read" in Isizulu/Isiswati*



 Project Overview

ImfundoBooks is a student-to-student marketplace web application designed to make prescribed textbooks affordable and accessible across African higher education institutions. Built by students, for students, the platform enables secure buying, selling, and exchanging of textbooks within a trusted campus community.

 The Problem We Solve

A single prescribed textbook can cost over R1000, forcing many students to:
- Share books with multiple classmates
- Spend hours in overcrowded libraries
- Sacrifice other essentials to afford materials
- Drop or fail courses due to lack of resources

 Our Solution

SomaShare connects students directly, eliminating middlemen and reducing costs through:
- Peer-to-peer textbook listings
- Fair price negotiation through offers
- Community trust scores based on successful transactions
- Safe, cash-based campus meetups



 Key Features

 User Management


|  Secure Registration | University email validation only |
|  Role-Based Access | Student and Admin roles |
|  Password Reset | Secure password recovery |
|  Profile Management | Update personal details |

Textbook Marketplace
|  Create Listings | Add books with title, author, ISBN, condition, price, campus, images |
|  Edit Listings | Update or modify existing listings |
|  Delete Listings | Remove sold or unwanted listings |
|  Search & Filter | Search by title, author, ISBN, price range, condition, campus |

 Offer & Transaction System
|  Make Offers | Propose a price on any available textbook |
|  Accept/Reject Offers | Sellers control the negotiation |
|  Transaction Records | Automatic tracking of accepted offers |
|  Cash on Meetup | Safe, in-person campus exchanges |

 Community & Trust
|  Trust Score | 1-5 star rating based on completed transactions |
|  Reviews | Leave feedback after each transaction |
|  Leaderboard | Most trusted community members |
|  Ubuntu Principles | Community-driven support system |

 Africanisation Features
|  Ubuntu Trust Score | Reputation system based on community values |
|  Cash on Meetup | Cash-based campus exchanges (no online payments) |
|  Multilingual Support | English / Kiswahili toggle |
|  "Harambee" Terminology | Culturally appropriate community terms |
